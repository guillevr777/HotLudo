# HotLudo

HotLudo es un juego tipo Ludo / Parchis hecho en Unity.

## Estructura

- `Assets/`: escenas, scripts, prefabs, animaciones y recursos.
- `Packages/`: dependencias del proyecto.
- `ProjectSettings/`: configuracion de Unity.
- `Extras/ProyectoMonja/`: proyecto adicional separado del portfolio principal.

## Lo que se ve en el juego

- Tablero con recorrido principal y caminos finales.
- Sistema de turnos para 4 jugadores.
- Lanzamiento de dado con animacion.
- Movimiento de fichas por corutinas.
- UI de turno con color y sprite por jugador.
- Flujo de menus y seleccion de jugadores.

## Stack

- Unity 6000.2.5f1
- C#
- Input System
- TextMesh Pro
- URP
